Node.js项目依赖管理解析

背景

使用npm install安装hexo后发现目录下多了node_modules这个文件夹。

为什么会出现 node_modules？

  1. 依赖管理：
    • 当你运行 npm install 时，Node.js 的包管理器（npm）会根据 package.json 文件自动下载项目所需的依赖包，并存储在 node_modules 文件夹中。
    • 例如，如果你安装了 lodash，它会被下载到 node_modules/lodash。
  2. 本地安装：
    • 默认情况下，npm install 会把依赖安装在当前项目的 node_modules 下，而不是全局（除非你加了 -g 参数）。
  3. 自动生成：
    • 这个文件夹通常不会被手动创建，而是由 npm自动生成，用于存放所有第三方库的代码。

如何处理呢？

1. 删除 node_modules 和相关文件

直接使用 rm -rf（推荐，Git Bash 默认支持）

2. 全局 npm配置（Git Bash 兼容写法）

(A) 查看/修改全局安装路径

⚠️ 路径格式注意：

  • Git Bash 默认使用 Linux 风格路径（/c/Users/xxx），但设置 npm 全局路径时建议用 D:/node_global（正斜杠）或 D:\\node_global（双反斜杠），避免转义问题。
(B) 将新路径加入系统环境变量

右键 此电脑 → 属性 → 高级系统设置 → 环境变量 → 在 Path 中添加 D:\node_global。
